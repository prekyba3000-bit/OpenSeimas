## Vote tallies

Migration 022 was already applied and all 5,279 rows already carried
tallies — the daily sync had been running the updated ingest, so the
prepared backfill script was never needed. **I did not put that data
there, so I verified it rather than trusting it:**

- Internal consistency: `už + prieš + susilaikė = balsavo` on all 5,279
  rows, no exceptions.
- 20 random votes fetched live from `apps.lrs.lt` and compared field by
  field: **20/20 exact, 0 mismatches, 0 unreachable.**
- `result_type` still NULL on all 5,279 — as designed. Nothing infers
  an outcome from the tallies.

## What the invariant audit found

Two more instances of the pattern the corrections log now names.

**Zeros standing in for missing metrics.** Three leaderboard cells read
`(readMpDimension(row, dim) ?? 0).toFixed(1)`, printing „0,0" for a
member with no source data. In a table sorted by that metric, 0.0 reads
as *worst in parliament*, not as *unknown*. Now „—", with a grep test so
the pattern cannot come back.

**An all-absent chamber.** 1,653 of 5,279 votes (31%) have no recorded
per-member choices; every one carries the LRS comment that the
electronic results disagree with the protocol totals. Had one been the
most recent vote, the seat map's „Balsavimas" mode would have painted
140 hollow seats „Nedalyvavo" — asserting the whole Seimas skipped a
vote. The mode is withheld for those votes.

## Accessibility

**No focus ring existed anywhere.** The base layer applied
`outline-ring/50`, which sets the outline's colour and width but never
its *style* — so `outline-style` computed to `none` on all 172 focusable
elements. Eighteen components had their own `focus-visible:` rules; the
rest had nothing. One rule now covers all of them, measured at 4.52 and
4.80 in light, 6.27 and 5.69 in dark, against a 3:1 requirement.

Contrast for the whole palette is regenerated by
`scripts/contrast-report.py`, which reads the tokens from source rather
than carrying a copy: `docs/reviews/jaukumas-contrast.md`.
