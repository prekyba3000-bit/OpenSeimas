# Evaluation CORA-06 — source-bound summary claims

2026-11-25. Branch `fix/eval-stage1`, code commit `3e28f05`.

## What changed

- The summary figure gate no longer treats numbers as an unlabelled multiset.
  Every figure must retain the source-bound label emitted by its template, so
  swapping „už“ and „prieš“ counts, moving counts between bill stages, or
  changing a vote's month is rejected.
- The existing statement that the source publishes no outcome is now a required
  claim for vote and bill summaries. Removing or altering it is rejected.
- When `outcome_published` is false, additional outcome assertions such as
  „Klausimas priimtas“ or „Projektas tapo įstatymu“ are rejected.
- Unrelated literal wording remains rephraseable; source spans and required
  factual claims remain unchanged.
- Approval uses the same strengthened gate, and a real-Postgres route test
  proves relabelled figures, an altered month and an invented outcome cannot be
  approved or become public.
